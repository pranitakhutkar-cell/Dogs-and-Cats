# 🐾 Paws & Whiskers — Dogs and Cats Website

## About
Paws & Whiskers is a responsive front-end website about dogs and cats. It includes pet galleries, pet-care tips, navigation, and a demo contact form.

## Features
- Home banner and navigation links
- Dog and cat image galleries
- Basic pet-care tips
- Responsive layout for desktop and mobile
- Demo contact form with JavaScript response
- Automatic copyright year

## Technologies
- HTML5
- CSS3
- JavaScript
- Unsplash images (internet connection required)

## Project Structure
```text
Dogs-and-Cats-Website/
├── index.html
└── README.md
```

## Run the Website
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Internet access is needed for the online pet images.

### Open using Git Bash on Windows
Navigate to the project folder and run:
```bash
explorer.exe index.html
```

## Push to GitHub
From the project folder:
```bash
git add index.html README.md
git commit -m "Add Dogs and Cats website"
git push
```
If no upstream branch is configured, use `git push -u origin main` (or replace `main` with your current branch).

## Note
The contact form is a front-end demo only. It does not send or store messages.
